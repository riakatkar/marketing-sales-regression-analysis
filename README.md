# Marketing & Sales Prediction Using Linear and Regularized Regression

## Project Overview
This project explores the relationship between marketing expenditure and sales using Linear Regression and regularized regression techniques.

## Objectives
- Explore relationships between marketing variables and sales.
- Build regression models to predict sales.
- Compare Linear Regression with Ridge, Lasso, and ElasticNet.
- Evaluate model performance using appropriate metrics and cross-validation.

## Models Used
- Linear Regression
- Ridge Regression
- Lasso Regression
- ElasticNet Regression

## Tools & Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

## Project Workflow
1. Data loading and exploration
2. Data preprocessing
3. Exploratory Data Analysis
4. Model training
5. Regularization and cross-validation
6. Model evaluation and comparison

## Repository Contents
- `Marketing Sales Prediction.ipynb` — notebook containing the analysis and model implementation.

## Key Learnings
Understanding regression, regularization, model evaluation, and the importance of comparing models before selecting a final model.
